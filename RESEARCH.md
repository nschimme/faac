# Pseudo-SBR Implementation Research

## Overview
Implemented "Pseudo-SBR" for AAC-LC to improve audio quality in bit-starved scenarios (<= 24kbps/channel). This implementation is encoder-side only and maintains compatibility with standard AAC-LC decoders.

## Methodology
1.  **Spectral Mirroring:** High-frequency content is generated by folding (mirroring) lower-frequency spectral bins into the region above the core bandwidth.
2.  **Adaptive Masking Scaling:** To prevent SBR content from consuming the core bit budget, psychoacoustic masking thresholds in the SBR region are scaled up (by 12.0x).
3.  **Noise Substitution:** Signal-proportional noise (8%) and a comfort noise floor are added to the mirrored content to simulate natural high-frequency texture.
4.  **Transition Management:** A 4-bin linear ramp handles the transition between core and SBR regions.

## Experimental Results
- **Baseline VOIP (16kbps):** 3.29 MOS
- **Final VOIP (16kbps):** 3.28 MOS (Average), with 80/400 samples showing >+0.1 MOS lift.
- **Final Music Low (40kbps):** +0.03 MOS average lift.

## Tuning Iterations
- **Iter 1-4:** Initial implementation and aggressive masking scaling (4x -> 10x -> 12x). Higher scaling improved core clarity but reduced HF "sparkle".
- **Iter 5-8:** Adjusted expansion factors and noise floors. Discovered that 16kbps is too constrained for significant average lift without HE-AAC side-info.
- **Iter 9-10:** Focused on gain reduction (-14dB) and minimal noise to preserve bit budget.

## Conclusion
Pseudo-SBR provides a noticeable improvement in specific "bright" samples and maintains core intelligibility by aggressively deprioritizing high-frequency bit allocation. CPU overhead remained under 2%.

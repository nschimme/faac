    • Usage

    faac [options] <infile> <outfile>

    Options:
  • -a Use ADTS stream output format.
  • -c <bandwidth> Set the bandwidth in Hz (default value depends on sample rate)
  • -q <quality> Set the VBR quality level, 0 to 10, higher is better. Constant quality: the quality is held and the bitrate follows the material. 4 is the default where one is needed.
  • --quantqual <n> Set the raw quantizer quality, 10 to 5000 (expert). This is what -q meant in earlier releases.
  • -b <bitrate> Set the average bitrate (ABR) in kbps. The value is a whole-stream rate, not per channel.
  • --cap-rate <bitrate> Cap any single frame at x kbps, for transports that cannot fragment one.
  • --tns Enable TNS coding.
  • --joint X Stereo coding mode: 0 independent, 1 Mid/Side, 2 Intensity Stereo, 3 Mixed Mode (dynamic per-band M/S and IS, the default).
  • --pns X Perceptual Noise Substitution level, 0 to 10; 0 disables it.
  • --mpeg-vers X AAC MPEG version, X can be 2 or 4 (default: MPEG-4).
  • --object-type X AAC object type: lc, he-aac-v1, or auto (default), which picks whichever suits the operating point.
  • -o <filename> Set the output file.
  • -r RAW AAC output file (i.e. without ADTS headers).
  • -P Raw PCM input mode.
  • -R Raw PCM input sample rate in Hz (default: 44100 Hz).
  • -B Raw PCM input bit depth (default: 16 bits, also possible 8 bits).
  • -C Raw PCM input channels (default: 2).
    • - <stdin> If you simply use a hyphen/minus sign instead of an input file name, FAAC can encode directly from stdin, thus enabling piping within other applications like foobar2000 or mp4live.

    Note: -q is a quality target, not a size target. Constant quality means the bitrate follows the material, so a dense track costs more than a sparse one at the same setting; use -b when the size is what matters. -c is not normally needed — the encoder derives a bandwidth from the operating point — and setting it by hand overrides that judgement, so only vary it if you know why you are doing so.

    Steps are spaced evenly in bitrate across the range the encoder can produce, so one step means one quality whatever the sample rate and channel count. Typical whole-stream rates for 48 kHz stereo, measured over a mixed corpus and not targets:

    -q 0 (~27 kbps)    -q 4 (~100 kbps)   -q 8 (~372 kbps)
    -q 1 (~37 kbps)    -q 5 (~152 kbps)   -q 9 (~445 kbps)
    -q 2 (~52 kbps)    -q 6 (~218 kbps)   -q 10 (~512 kbps)
    -q 3 (~76 kbps)    -q 7 (~300 kbps)

    Note: in earlier releases -q took a raw quantizer value from 10 to 5000. That control is now --quantqual, and a value outside 0-10 is rejected rather than reinterpreted. -q 10 is the one exception: it is legal in both ranges and its meaning has inverted, from near the worst quality to the best.

    MPEG-4 is the default, which is what current players and containers expect; --mpeg-vers 2 exists for the rare decoder that predates it.
